## 极简电视 TVLive v1.0

给老人用的电视直播 App。**打开就是台，上下键换台，OK 键挑台**，其余一概不做。

- 体积 **37 KB**，零第三方依赖，无 Gradle / 无 AndroidX
- 支持 Android 5.0+（minSdk 21），TV / 盒子 / 手机都能装
- 同时注册普通启动器和 Android TV Leanback 入口

### 安装

```bash
adb connect 192.168.1.x:5555
adb install -r TVLive-1.0.apk
```

或拷到 U 盘，用电视自带文件管理器安装。

### 按键

| 按键 | 行为 |
|---|---|
| ▲ / ▼ | 上一个台 / 下一个台（循环） |
| OK | 弹出频道列表：左右换分类，上下选台，OK 播放 |
| 数字键 | 输入台号直接跳转（如 `1` `2` → 012 台） |
| 返回 | 弹出 / 收起频道列表（不会误退出 App） |

### 本版内容

- **内置 38 个频道**，全部在一台 Android 电视上逐台实测播出画面后保留：
  - 央视 18 个：CCTV-1 ~ CCTV-17 全套（含 5+）
  - 卫视 11 个：东方、浙江、湖南、黑龙江、河北、东南、大湾区、广西、延边、内蒙古、人间
  - 其他 9 个：CGTN 六语种、CHC 电影、央视台球、浙江钱江
- 一个频道可挂多个源，播放失败自动切换；全源失败后再重试 2 次
- 15 秒看门狗兜底，不会永远卡在"正在打开…"
- 播放失败时信息条常驻并说明原因，避免老人对着黑屏
- 记住上次观看的频道，冷启动直接续播
- 可外部覆盖播放列表（`/sdcard/Android/data/com.mini.tvlive/files/playlist.m3u`），换源不用重装
- 保留两个调试开关：`dotest.marker`（源自检）、`statelog.marker`（播放结果日志）

### 注意

- 内置源是公开网络地址的一份快照，**随时可能失效**，且能否播放取决于你家的宽带（移动/电信/联通、IPv4/IPv6 各不相同）。建议换成自己手上的源，README 里有格式说明。
- 公共 IPTV 网关会按 IP 限流，批量探测时并发不要开大。
- **签名用的是演示 keystore**（`tools/demo.jks`，口令 `tvlive123`）。要长期分发请自行换 keystore 重新构建。
